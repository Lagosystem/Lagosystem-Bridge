# Lagosystem Bridge v0.2.0-beta.1

**PRE-RELEASE / VERSÃO EXPERIMENTAL — NOT PRODUCTION READY / NÃO HOMOLOGADA PARA PRODUÇÃO**

Lagosystem Bridge is a vendor-neutral C++20 Native Messaging bridge with Chromium and Firefox extensions. It **does not require a Lagosystem ERP/SaaS account, tenant, API or cloud service**.

## Included packages / Pacotes distribuídos

- **Windows x64:** MSVC C++20 native host, user-level installation scripts and manifests.
- **Linux x64:** C++20 binary built on Ubuntu 24.04; no guarantee of compatibility with older glibc/distributions.
- **macOS ARM64:** Apple Clang C++20 build for Apple Silicon, not Intel.
- **Chromium extension:** Manifest V3 development ZIP; not a signed Chrome Web Store package.
- **Firefox extension:** Manifest V3 development ZIP; not signed by Firefox Add-ons (AMO) and not necessarily installable as a permanent extension.
- **SHA-256 checksum** next to each archive.
- **Licenses:** GNU GPL-3.0-or-later for the Bridge and MIT attribution for embedded `nlohmann_json`.

## Safety, testing and limitations / Segurança e limitações

The C++ host refuses execution as administrator or root and requires scoped browser-site and device authorization. The CI compiles across Windows, Linux and macOS and validates simulated browser adapters; it does **not** test real browser add-on stores, physical printer output, real scales, vendor protocols, fiscal certification, legal-for-trade measurements or production deployments.

**Windows binaries are not Authenticode signed, macOS binaries are not notarized and the WebExtensions are not store signed.** Do not bypass corporate trust policies. Serial permissions, GTK availability on Linux, and USB-to-serial drivers remain system-dependent.

## Install / Instalação

1. Download the host archive matching your OS/architecture and its matching `.sha256` file. Verify the hash before extracting.
2. Extract to a location accessible to your **standard, non-elevated user**.
3. **Windows:** run `install-windows.ps1` with the absolute path to `bin/lagosystem-bridge.exe` and the real Chromium extension ID(s); Firefox registration is included. Never run elevated.
4. **Linux/macOS:** use `bash install-unix.sh /absolute/path/to/bin/lagosystem-bridge [CHROMIUM_EXTENSION_ID]` without sudo/root. Omit the ID if using only Firefox. Ensure the native binary is executable.
5. Unpack `chromium.zip` / `firefox.zip` and load their directories using the browser's developer extension tools. Permanent Firefox installation generally requires Mozilla add-on signing; these packages are intentionally unsigned.
6. Approve your HTTPS website in the extension's own popup. First call `detect`, `ping` and `capabilities` before requesting devices.
